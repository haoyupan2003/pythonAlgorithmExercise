## Introduction
This repository serves as a log of my personal algorithm practice. I'll be adding problems I've solved, along with explanations, solutions, and any insights I gained. The problems range from easy to hard, and they are often categorized by the type of algorithm or data structure they involve.

## Practices
Every practice session will have a dedicated entry in this repository. Here are some typical contents for each entry:
- **Problem Description:** A brief summary of the algorithm problem.
- **Solution:** The code I used to solve the problem.
- **Explanation:** A step-by-step explanation of the solution, covering key concepts and how the algorithm works.
- **Time Complexity:** Analysis of the time and space complexity of the solution.
- **Challenges:** Any difficulties I encountered and how I overcame them.

You can explore my logs by browsing through the folders and files.
